# Backlog — user directions (2026-08-10)

Direct instructions from Ars. Each item is a requirement; do not treat as
optional. Guidance, not history.

## Conversation steering

- Requirement: the user must be able to send SUBSEQUENT messages to
  steer the agent — the first message starts the task, and the
  follow-ups ("the second one", "no, the other track", "now continue
  writing") drive the rest. Without subsequent messages, conversation
  cannot happen properly: the agent offers options and the user must be
  able to answer with a follow-up turn. Verify this path in the
  packaged app: offer -> user picks via a NEW message -> the agent
  acts on the pick.
