# Backlog — user directions 2026-08-08

Live user directions from the evening demo session. Each item is a direct
instruction; do not treat as optional.

## Policy: frictionless by default

- No confirmation gates except MAYBE messages and email. Everything else
  must feel frictionless (media.play etc. — in progress, pol-1).
- Confirmation UX (if any): a popup IN the chat, or open the mic and ask
  for voice confirmation. No silent pending gates where the model says
  "done" while the action waits.

## UI / state panel

- The state panel should be MINIMAL — not a header.
- Embed it close to where the user's eyes naturally land: either always in
  the chat, or below/side of the main panel.

  (it does not reflect iframe playback position) — fix in a later wave.
